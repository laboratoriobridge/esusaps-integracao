    Data Warehouse Relatórios e-SUS APS PEC

    Gerar PDF desta página Alterado em 23/11/2026

    1. Objetivo

    Esta seção descreve a estrutura de Data Warehouse (DW) onde são armazenados os dados para a geração dos relatórios.

    O DW é uma base de dados contendo vários componentes, organizados em camadas com responsabilidades distintas:

    • Fatos e Dimensões formam a arquitetura multidimensional do DW. São estruturas dependentes entre si e armazenam os eventos processados a partir dos modelos de informação;
    • o Data Mart é a camada de serving, com tabelas derivadas e pré-computadas para consumo direto por telas, consultas e relatórios;
    • o ODS mantém o estado operacional corrente do PEC, integrado a partir da base transacional.

    Através de um sistema de ETL, as informações são extraídas de arquivos conforme descritos na estrutura Layout e-SUS APS de Dados e Interface e armazenadas nas tabelas Fatos e Dimensões. A partir delas, um processamento assíncrono aplica as regras de negócio do PEC e materializa as tabelas do Data Mart. As tabelas do ODS, por sua vez, são populadas diretamente a partir dos dados transacionais do PEC.

    As Dimensões possuem características descritivas dentro do DW. São responsáveis por qualificar as informações provenientes das tabelas Fatos. As tabelas Fatos possuem características quantitativa dentro do DW. A partir delas, são extraídas métricas que são cruzadas com os dados das Dimensões, gerando informações significativas para a avaliação do usuário. Todos os dados históricos no DW ficam armazenadas nas tabelas Fatos.

    As tabelas do Data Mart e do ODS não possuem dados históricos: elas refletem a situação corrente dos dados de acordo com o último processamento realizado.

    IMPORTANTE: até a versão 5.5.25 do e-SUS APS PEC existia uma seção denominada "Visualizações",
que foi substituída pelo conceito de ODS.

    As alterações da estrutura estão descritas em Principais alterações entre versões.
