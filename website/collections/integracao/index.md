Esta página apresenta os documentos de integração do e-SUS APS. Atualmente são disponibilizadas as documentações **LEDI** e **DW PEC**.

## 1. LEDI APS

O Layout e-SUS APS de Dados e Interface (LEDI APS) permite a integração de sistemas próprios com o e-SUS APS PEC. Esta integração pode ser realizada através das tecnologias Apache Thrift, XML ou via API e é independente de linguagem de programação.

## 2. DW PEC

A estrutura de Data Warehouse do e-SUS APS PEC (DW PEC) é responsável por armazenar os dados utilizados para a geração dos relatórios do sistema de Prontuário Eletrônico do Cidadão da Atenção Primária. A documentação DW PEC tem o objetivo de orientar os profissionais com conhecimento em banco de dados a extrair informações que julgarem pertinentes.

## 3. Sistemas externos no Prontuário Eletrônico e-SUS APS

Sistemas externos, também conhecidos como sistemas embutidos ou embedded (embarcados), permitem que sejam configurados sistemas fora do domínio do Prontuário Eletrônico e-SUS APS para apresentação dentro do próprio contexto do sistema, ou seja, sem a necessidade de abrir uma nova guia do navegador.
