## 1. Objetivo

A tabela `tb_fat_atendimento_domiciliar` é populada sempre que os dados de um :link[Atendimento Domiciliar]{id=dicionario-fad} são processados. Ela armazena o cabeçalho do atendimento e as condições avaliadas nas opções rápidas.

## 2. Regras

:nr A `tb_fat_atendimento_domiciliar` é preenchida quando são processado(a)s:

- Fichas de atendimento domiciliar recebidas através da importação de sistemas terceiros ou outras instalações do PEC;
- Registros de atendimento domiciliar realizados no CDS ou no aplicativo e-SUS Atenção Domiciliar.

## 3. Fatos

### 3.1 Metadados dos fatos

| Colunas DW | Referência LEDI | Referência sistema |
| ---------- | --------------- | ------------------ |
| co\_seq\_fat\_atend\_domiciliar | - | Código de identificação sequencial criado automaticamente pelo sistema |
| nu\_uuid\_ficha | :link[uuidFicha]{id=dicionario-fad anchor=1-uuidficha} | Identificador universalmente único do registro |
| nu\_uuid\_dado\_transp | - | Identificador universalmente único da camada de transporte de dados. Caso o registro seja gerado dentro do PEC terá o mesmo valor do campo nu\_uuid\_ficha |
| co\_fat\_cidadao\_pec | - | Campo `co_seq_fat_cidadao_pec` da `tb_fat_cidadao_pec` |
| nu\_cns | :link[cnsCidadao]{id=dicionario-fad anchor=2-cnscidadao} | CNS do cidadão |

## 4. Dimensões da tabela

### 4.1 Dimensões específicas dessa tabela

| Coluna DW | Dimensão referência |
| --------- | ------------------- |
| co\_dim\_faixa\_etaria | Código da faixa etária do cidadão. Campo `co_seq_dim_faixa_etaria` da `tb_dim_faixa_etaria` |
| co\_dim\_just\_nao\_possui\_cpf | Código da justificativa de não possuir CPF. Campo `co_seq_dim_just_nao_possui_cpf` da `tb_dim_just_nao_possui_cpf` |
| co\_dim\_sexo | Código do sexo do cidadão. Campo `co_seq_dim_faixa_sexo` da `tb_dim_sexo` |
| co\_dim\_local\_atendimento | Código do local de atendimento. Campo `co_seq_dim_local_atendimento` da `tb_dim_local_atendimento` |
| co\_dim\_tipo\_atendimento | Código do tipo de atendimento. Campo `co_seq_dim_tipo_atendimento` da `tb_dim_tipo_atendimento` |
| co\_dim\_modalidade\_ad | Código da modalidade de atenção domiciliar. Campo `co_seq_dim_modalidade_ad` da `tb_dim_modalidade_ad` |
| co\_dim\_conduta\_ad | Código da conduta de atenção domiciliar. Campo `co_seq_dim_conduta_ad` da `tb_dim_conduta_ad` |
