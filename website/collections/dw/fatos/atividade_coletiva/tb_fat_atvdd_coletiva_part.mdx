## 1. Objetivo

A tabela `tb_fat_atvdd_coletiva_part` registra os **cidadãos participantes** de uma atividade coletiva. Cada linha representa um participante individual e armazena dados de identificação, antropometria e avaliação.

## 2. Regras

:nr A `tb_fat_atvdd_coletiva_part` é preenchida quando é processado registro de atividade coletiva em que são informados participantes individuais.

## 3. Fatos

### 3.1 Metadados dos fatos

| Colunas DW | Referência LEDI | Referência sistema |
| ---------- | --------------- | ------------------ |
| co\_seq\_fat\_atvdd\_cltv\_part | - | Código de identificação sequencial do cidadão participante de um atividade coletiva |
| co\_fat\_atividade\_coletiva | - | Campo `co_seq_fat_atividade_coletiva` da `tb_fat_atividade_coletiva` |
| nu\_uuid\_ficha | :link[uuidFicha]{id=dicionario-fac anchor=1-uuidficha} | Identificador universalmente único do registro |
| nu\_uuid\_dado\_transp | :link[uuidDadoSerializado]{id=camada-transporte anchor=1-uuiddadoserializado} | Identificador universalmente único da camada de transporte de dados |
| co\_fat\_cidadao\_pec | - | Campo `co_seq_fat_cidadao_pec` da `tb_fat_cidadao_pec` |
| nu\_participante\_cns | :link[cnsParticipante]{id=dicionario-fac anchor=1-cnsparticipante} | CNS do participante |
| nu\_cpf\_participante | :link[cpfParticipante]{id=dicionario-fac anchor=9-cpfparticipante} | CPF do participante |
