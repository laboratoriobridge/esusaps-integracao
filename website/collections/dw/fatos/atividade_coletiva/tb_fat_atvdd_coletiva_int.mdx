## 1. Objetivo

A tabela `tb_fat_atvdd_coletiva_int` é populada quando o tipo de atividade processada corresponde a uma **reunião de equipe**. Cada registro armazena os temas para reunião e os temas para saúde selecionados nesta modalidade.

## 2. Regras

:nr A `tb_fat_atvdd_coletiva_int` é preenchida quando:

- O tipo de atividade da `tb_fat_atividade_coletiva` refere-se à uma reunião.
