## 1. Objetivo

A tabela `tb_fat_atend_odonto_exames` só é preenchida quando são processados registros de resultado de exame estruturados feitos em um :link[atendimento odontológico]{id=dicionario-fao} e o atendimento em questão é processado.

## 2. Regras

:nr A `tb_fat_atend_odonto_exames` é preenchida de acordo com as :link[regras]{id=dicionario-fao anchor=22-resultadosexames}.

## 3. Fatos

### 3.1 Metadados dos fatos

| Coluna DW                      | Referência LEDI | Referência sistema |
| ------------------------------ | --------------- | ------------------ |
| co\_seq\_fat\_atd\_odo\_exames | -               | Código de identificação sequencial dos resultado de exame estruturados registrados |

## 4. Dimensões da tabela

### 4.1 Dimensões específicas dessa tabela

| Coluna DW                          | Dimensão referência |
| ---------------------------------- | ------------------- |
| co\_dim\_procedimento\_avaliado    | Código SIGTAP do exame avaliado. Campo `co_seq_dim_procedimento` da `tb_dim_procedimento` |
| co\_dim\_procedimento\_solicitado  | Código SIGTAP do exame solicitado. Campo `co_seq_dim_procedimento` da `tb_dim_procedimento` |
| co\_dim\_sexo | Código do sexo. Campo `co_seq_dim_faixa_sexo` da `tb_dim_sexo` |
| co\_dim\_turno | Código do turno do atendimento. Campo `co_seq_dim_turno` da `tb_dim_turno` | 
| co\_dim\_tipo\_atendimento | Código do tipo de atendimento. Campo `co_seq_dim_tipo_atendimento` da `tb_dim_tipo_atendimento` | 
| co\_dim\_faixa\_etaria | Código da faixa etária. Campo `co_seq_dim_faixa_etaria` da `tb_dim_faixa_etaria` |
