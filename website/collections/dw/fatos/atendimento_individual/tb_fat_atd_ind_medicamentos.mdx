## 1. Objetivo

A tabela `tb_fat_atd_ind_medicamentos` só é preenchida quando são processados registros de preescrição de medicamentos em um :link[atendimento individual]{id=dicionario-fai} e o atendimento em questão é processado. 

## 2. Fatos

### 2.1 Metadados dos fatos

| Colunas DW | Referência LEDI | Referência sistema |
| ---------- | --------------- | ------------------ |
| co\_seq\_fat\_atd\_ind\_medicam | - | Código de identificação sequencial dos medicamentos registrados |
| co\_fat\_atd\_ind | - | Código de identificação sequencial do atendimento individual. Campo `co_seq_fat_atd_ind` da `tb_fat_atendimento_individual` |
| co\_fat\_cidadao\_pec | - | Campo `co_seq_fat_cidadao_pec` da `tb_fat_cidadao_pec` |
| nu\_cpf\_cidadao | :link[cpfCidadao]{id=dicionario-fai anchor=24-cpfcidadao} | CPF do cidadão |
| nu\_cns\_cidadao |  :link[cnsCidadao]{id=dicionario-fai anchor=2-cnscidadao} | CNS do cidadão |
| nu\_uuid\_ficha | :link[uuidFicha]{id=dicionario-fai anchor=3-uuidficha} | Identificador universalmente único da camada de transporte de dados |
| nu\_uuid\_dado\_transp | - | Identificador universalmente único da camada de transporte de dados. Caso o registro seja gerado dentro do PEC terá o mesmo valor do campo nu\_uuid\_ficha | 
| nu\_atendimento | - | Uma ficha pode conter mais de um atendimento esse campo é utilizado para ordenar os atendimentos dentro um mesmo envio |

### 2.2 Métricas dos Fatos

| Colunas DW | Referência LEDI | Referência sistema |
| ---------- | --------------- | ------------------ |
| ds\_dose | :link[dose]{id=dicionario-fai anchor=3-dose} | Descrição da dose prescrita composta pela quantidade da dose e unidade de medida| 
| st\_dose\_unica | :link[doseUnica]{id=dicionario-fai anchor=4-doseunica}  | Status que indica se a dose é única | 
| st\_uso\_continuo | :link[usoContinuo]{id=dicionario-fai anchor=5-usocontinuo} | Status que indica se o medicamento é de uso contínuo | 
| ds\_dose\_frequencia | :link[doseFrequencia]{id=dicionario-fai anchor=7-dosefrequencia} | Descrição da duração de dias do tratamento | 
| qt\_dose\_frequencia | :link[doseFrequenciaQuantidade]{id=dicionario-fai anchor=8-dosefrequenciaquantidade} | Descrição da quantidade de unidades de medicamento que devem ser utilizadas em um período específico definido pelo profissional de saúde | 
| qt\_duracao\_tratamento | :link[duracaoTratamento]{id=dicionario-fai anchor=11-duracaotratamento} | Quantidade de dias, semanas ou meses que o tratamento deve durar | 
| qt\_dose\_manha | - | Quantidade da dose fracionada para o turno da manhã |
| qt\_dose\_tarde | - | Quantidade da dose fracionada para o turno da tarde |
| qt\_dose\_noite | - | Quantidade da dose fracionada para o turno da noite |
| qt\_receitada | :link[quantidadeReceitada]{id=dicionario-fai anchor=13-quantidadereceitada} | Quantidade de medicamentos receitados | 
| dt\_inicio\_tratamento | :link[dtInicioTratamento]{id=dicionario-fai anchor=10-dtiniciotratamento} | Data de início do tratamento |
