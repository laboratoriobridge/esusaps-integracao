## 1. Objetivo

A tabela `tb_fat_cad_domiciliar` é populada sempre que os dados de um :link[Cadastro Domiciliar e Territorial]{id=dicionario-fcd} são processados.

## 2. Regras

:nr A `tb_fat_cad_domiciliar` é preenchida quando são processado(as):

- Fichas de cadastro domiciliar recebidas através da importação de sistemas terceiros, outras instalações do PEC e-SUS-APS ou do aplicativo e-SUS Território;
- Registro de um cadastro domiciliar realizado no CDS, no Acompanhamento do Território ou na Reterritorialização.

## 3. Fatos

### 3.1 Metadados dos fatos

| Colunas DW | Referência LEDI | Referência sistema |
| ---------- | --------------- | ------------------ |
| co\_seq\_fat\_cad\_domiciliar | - | Código de identificação sequencial criado automaticamente pelo sistema |
| nu\_uuid\_ficha | :link[uuid]{id=dicionario-fcd anchor=10-uuid} | Identificador universalmente único do registro |
| nu\_uuid\_ficha\_origem | :link[uuidFichaOriginadora]{id=dicionario-fcd anchor=11-uuidfichaoriginadora} | UUID original da ficha de origem. Utilizado para vincular visitas domiciliares ao domicílio cadastrado |
| nu\_uuid\_dado\_transp | :link[uuidDadoSerializado]{id=camada-transporte anchor=1-uuiddadoserializado} | Identificador universalmente único da camada de transporte de dados. Caso o registro seja gerado dentro do PEC terá o mesmo valor do campo nu\_uuid\_ficha |
| st\_recusa\_cadastro | :link[statusTermoRecusa]{id=dicionario-fcd anchor=8-statustermorecusa} | Indica se houve recusa ao cadastramento do domicílio |
| st\_gerado\_automaticamente | - | Indica se o registro foi gerado automaticamente pelo sistema |
| st\_proc\_operacionais | - | Flag de controle de processamento operacional |
| st\_processa\_familita\_terrtro | - | Flag de controle de processamento de famílias no território |
| st\_processo\_linha\_tempo | - | Flag de controle de processamento na linha do tempo |
| st\_processo\_familia | - | Flag de controle de processamento de família |
| st\_familias | - | Flag que indica presença de famílias vinculadas ao domicílio |
| st\_ativo | - | Indica se o registro está ativo no sistema |
