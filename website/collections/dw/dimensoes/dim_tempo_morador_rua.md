## 1. Objetivo

A tabela `tb_dim_tempo_morador_rua` é utilizada para armazenar o tempo em situação de rua do cidadão. Possui como referência o :link[Tempo em situação de rua]{id=dicionario anchor=temposituacaoderua} do LEDI.

## 2. Campos da tabela

| Colunas DW | Referência |
| ---------- | ---------- |
| co\_seq\_dim\_tempo\_morador\_rua | Código de identificação sequencial |
| nu\_identificador | Número identificador do tempo em situação de rua |
| ds\_dim\_tempo\_morador\_rua | Descrição do tempo em situação de rua |
| co\_ordem | Código para ordenação |
