## 1. Objetivo

A tabela `tb_dim_desfecho_visita` é utilizada para armazenar os desfechos de visita. Possui como referência a tabela de :link[Desfecho Visita]{id=dicionario anchor=desfecho} do LEDI.

## 2. Campos da tabela

| Colunas DW | Referência      |
| ---------- | --------------- |
| co\_seq\_dim\_desfecho\_visita | Código de identificação sequencial |
| nu\_identificador | Número identificador do desfecho |
| ds\_desfecho\_visita | Descrição do desfecho |
| co\_ordem | Código para ordenação do desfecho |
