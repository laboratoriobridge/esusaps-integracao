## 1. Objetivo

A tabela `tb_dim_duracao_tratamento_med` é utilizada para armazenar as unidades de medida da duração do tratamento. Possui como referência a tabela de :link[Unidade de medida da duração do tratamento]{id=dicionario anchor=duracaotratamentomedida} do LEDI.

## 2. Campos da tabela

| Colunas DW | Referência      |
| ---------- | --------------- |
| co\_seq\_dim\_duracao\_trat\_med | Código de identificação sequencial |
| nu\_identificador | Número identificador da unidade de medida da duração do tratamento |
| nu\_duracao\_tratamento\_med | - |
| no\_duracao\_tratamento\_med | Nome da unidade de medida da duração do tratamento |
| no\_duracao\_tratamento\_med\_filt | Nome da unidade de medida da duração do tratamento, sem acentos |
| co\_ordem | Código para ordenação da dose do imunobiológico |
