## 1. Objetivo

A tabela `tb_dim_povo_comunidad_trad` é utilizada para armazenar os povos ou comunidades tradicionais. Possui como referência a :link[Tabela de Povo ou Comunidade Tradicional]{id=dicionario anchor=povocomunidadetradicional} do LEDI.

## 2. Campos da tabela

| Colunas DW | Referência      |
| ---------- | --------------- |
| co\_seq\_dim\_povo\_comunidad\_trad | Código de identificação sequencial |
| nu\_identificador | Número identificador do povo ou comunidade tradicional |
| ds\_povo\_comunidade\_tradicional | Descrição do povo ou comunidade tradicional |
