## 1. Objetivo

A tabela `tb_dim_condicao_maternal` é utilizada para armazenar as condições maternais da cidadã no momento da vacinação.

## 2. Campos da tabela

| Colunas DW | Referência |
| ---------- | ---------- |
| co\_seq\_dim\_condicao\_maternal | Código de identificação sequencial |
| nu\_identificador | Número identificador da condição maternal |
| ds\_condicao | Descrição da condição maternal |
| co\_ordem | Código para ordenação |
