## 1. Objetivo

A tabela `tb_dim_pic` é utilizada para armazenar as práticas integrativas complementares. Possui como referência a [Tabela de Práticas integrativas complementares](https://integracao.esusab.ufsc.br/v20/docs/dicionario/dicionario.html#praticasintegrativascomplementares) do LEDI.

## 2. Campos da tabela

| Colunas DW | Referência      |
| ---------- | --------------- |
| co\_seq\_dim\_pic | Código de identificação sequencial |
| nu\_identificador | Número identificador da prática integrativa complementar |
| ds\_pic | Descrição da prática integrativa complementar |
| co\_ordem | Código para ordenação da práticas integrativa complementar |
