## 1. Objetivo

A tabela `tb_dim_tempo_socioeducativo` é utilizada para armazenar os períodos de tempo de cumprimento de medida socioeducativa.

## 2. Campos da tabela

| Colunas DW | Referência |
| ---------- | ---------- |
| co\_seq\_tempo\_socioeducativo | Código de identificação sequencial |
| nu\_identificador | Número identificador do tempo socioeducativo |
| ds\_tempo\_socioeducativo | Descrição do tempo de cumprimento de medida socioeducativa |
