## 1. Objetivo

A tabela `tb_dim_modalidade_ad` é utilizada para armazenar as modalidades do atendimento domiciliar. Possui como referência a :link[Tabela de modalidade AD]{id=dicionario anchor=modalidadead}.

## 2. Campos da tabela

| Colunas DW | Referência      |
| ---------- | --------------- |
| co\_seq\_dim\_modalidade\_ad | Código de identificação sequencial |
| nu\_identificador | Número identificador da modalidade AD |
| ds\_modalidade\_ad | Descrição da modalidade AD |
| co\_ordem | Código para ordenação da modalidade AD |
