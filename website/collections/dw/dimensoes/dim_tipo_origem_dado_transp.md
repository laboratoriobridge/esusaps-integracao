## 1. Objetivo

A tabela `tb_dim_tipo_origem_dado_transp` é utilizada para armazenar a forma como o dado foi registrado na base.

## 2. Campos da tabela

| Colunas DW | Referência |
| ---------- | ---------- |
| co\_seq\_dim\_tp\_orgm\_dado\_transp | Código de identificação sequencial |
| nu\_identificador | Número identificador do tipo de origem do dado transportado |
| no\_tipo\_origem\_dado\_transp | Nome do tipo de origem do dado transportado |
