## 1. Objetivo

A tabela `tb_dim_tipo_tratamento_agua` é utilizada para armazenar os tipos de tratamento da água para consumo no domicílio. Possui como referência a :link[Água para consumo no domicílio]{id=dicionario anchor=aguaconsumodomicilio} do LEDI.

## 2. Campos da tabela

| Colunas DW | Referência |
| ---------- | ---------- |
| co\_seq\_dim\_tipo\_tratament\_agua | Código de identificação sequencial |
| nu\_identificador | Número identificador do tipo de tratamento da água |
| ds\_tipo\_tratamento\_agua | Descrição do tipo de tratamento da água |
| co\_ordem | Código para ordenação |
