## 1. Objetivo

A tabela `tb_dim_sexo` é utilizada para armazenar o cadastro de sexo. Possui como referência a :link[Tabela de sexo]{id=dicionario anchor=sexo} do LEDI.

## 2. Campos da tabela

| Colunas DW | Referência      |
| ---------- | --------------- |
| co\_seq\_dim\_sexo | Código de identificação sequencial |
| nu\_identificador | Número identificador do sexo |
| ds\_sexo | Descrição do sexo |
| sg\_sexo | Sigla do sexo |
| co\_ordem | Código para ordenação do sexo |
