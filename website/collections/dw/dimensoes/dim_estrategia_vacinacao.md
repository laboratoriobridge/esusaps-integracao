## 1. Objetivo

A tabela `tb_dim_estrategia_vacinacao` é utilizada para armazenar as estratégias de vacinação. Possui como referência a tabela de :link[Estratégia de vacinação]{id=dicionario anchor=estrategiavacinacao} do LEDI.

## 2. Campos da tabela

| Colunas DW | Referência      |
| ---------- | --------------- |
| co\_seq\_dim\_estrategia\_vacinacao | Código de identificação sequencial |
| nu\_identificador| Número identificador da estratégia de vacinação |
| nu\_estrategia\_vacinacao | Código RNDS da estratégia de vacinação |
| no\_estrategia\_vacinacao | Nome da estratégia de vacinação |
