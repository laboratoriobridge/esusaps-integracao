## 1. Objetivo

A tabela `tb_dim_municipio` é utilizada para armazenar os municípios. Possui como referência a :link[Tabela de municípios]{id=municipios} do LEDI.

## 2. Regras

:nr A tabela é preenchida sempre que um cidadão com um município diferente é cadastrado.

## 3. Campos da tabela

| Colunas DW | Referência      |
| ---------- | --------------- |
| co\_seq\_dim\_municipio | Código de identificação sequencial |
| no\_municipio | Nome do município |
| co\_ibge| Código do IBGE do município |
| co\_dim\_uf | Código da Unidade Federativa do município. Campo `co_seq_dim_uf` da `tb_dim_uf` |
| st\_registro\_valido | <CampoStRegistroValido /> |
| ds\_filtro | Concatenação entre o código do IBGE, nome e UF do município, sem acentos |
