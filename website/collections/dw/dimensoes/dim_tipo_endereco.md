## 1. Objetivo

A tabela `tb_dim_tipo_endereco` é utilizada para armazenar os tipos de endereço do domicílio.

## 2. Campos da tabela

| Colunas DW | Referência |
| ---------- | ---------- |
| co\_seq\_dim\_tipo\_endereco | Código de identificação sequencial |
| nu\_identificador | Número identificador do tipo de endereço |
| ds\_tipo\_endereco | Descrição do tipo de endereço |
| co\_ordem | Código para ordenação |
