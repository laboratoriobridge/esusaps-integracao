## 1. Objetivo

A tabela `tb_dim_raca_cor` é utilizada para armazenar as raças e cores. Possui como referência a :link[Tabela de raça / cor]{id=dicionario anchor=racacor} do LEDI.

## 2. Campos da tabela

| Colunas DW | Referência      |
| ---------- | --------------- |
| co\_seq\_dim\_raca\_cor | Código de identificação sequencial |
| nu\_identificador | Número identificador da raça / cor |
| nu\_ms | Número identificador do Ministério da Saúde |
| ds\_raca\_cor | Descrição da raça / cor |
| co\_ordem | Código para ordenação da raça / cor |
