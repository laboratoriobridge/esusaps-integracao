## 1. Objetivo

A tabela `tb_dim_tipo_posse_terra` é utilizada para armazenar as condições de posse e uso da terra em área de produção rural. Possui como referência a :link[Em caso de área de produção rural: condição de posse e uso da terra]{id=dicionario anchor=condicaodeposseeusodaterra} do LEDI.

## 2. Campos da tabela

| Colunas DW | Referência |
| ---------- | ---------- |
| co\_seq\_dim\_tipo\_posse\_terra | Código de identificação sequencial |
| nu\_identificador | Número identificador do tipo de posse da terra |
| ds\_tipo\_posse\_terra | Descrição do tipo de posse da terra |
| co\_ordem | Código para ordenação |
