## 1. Objetivo

A tabela `tb_dim_tipo_orientacao_sexual` é utilizada para armazenar os tipos de orientação sexual do cidadão. Possui como referência a :link[Orientação sexual]{id=dicionario anchor=orientacaosexual} do LEDI.

## 2. Campos da tabela

| Colunas DW | Referência |
| ---------- | ---------- |
| co\_seq\_dim\_tipo\_orientacao\_sxl | Código de identificação sequencial |
| nu\_identificador | Número identificador da orientação sexual |
| ds\_dim\_tipo\_orientacao\_sexual | Descrição da orientação sexual |
| co\_ordem | Código para ordenação |
