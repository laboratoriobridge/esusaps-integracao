## 1. Objetivo

A tabela `tb_dim_tipo_origem_energ_elet` é utilizada para armazenar os tipos de origem de energia elétrica do domicílio. Possui como referência o :link[Tipo de origem de energia elétrica]{id=dicionario anchor=tipoorigemenergiaeletrica} do LEDI.

## 2. Campos da tabela

| Colunas DW | Referência |
| ---------- | ---------- |
| co\_seq\_dim\_tp\_org\_energia\_elet | Código de identificação sequencial |
| nu\_identificador | Número identificador do tipo de origem de energia elétrica |
| ds\_tipo\_origem\_energia\_eletric | Descrição do tipo de origem de energia elétrica |
| co\_ordem | Código para ordenação |
