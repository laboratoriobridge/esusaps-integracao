## 1. Objetivo

A tabela `tb_dim_tipo_origem` é utilizada para armazenar o sistema de origem do registro. Indica qual sistema gerou a informação.

## 2. Campos da tabela

| Colunas DW | Referência |
| ---------- | ---------- |
| co\_seq\_dim\_tipo\_origem | Código de identificação sequencial |
| nu\_identificador | Número identificador do tipo de origem |
| no\_tipo\_origem | Nome do tipo de origem |
