## 1. Objetivo

A tabela `tb_dim_inep` é utilizada para armazenar os estabelecimentos do INEP. Possui como referência a tabela do INEP disponível nas :link[referências]{id=referencias}.

## 2. Regras

:nr Quando um estabelecimento do INEP é preenchido em uma atividade coletiva a tabela é preenchida.

## 3. Campos da tabela

| Colunas DW | Referência      |
| ---------- | --------------- |
| co\_seq\_dim\_inep | Código de identificação sequencial |
| nu\_identificador | Número identificador do INEP |
| no\_estabelecimento | Nome do estabelecimento do INEP |
| st\_registro\_valido | <CampoStRegistroValido /> |
