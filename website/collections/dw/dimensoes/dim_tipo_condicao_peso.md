## 1. Objetivo

A tabela `tb_dim_tipo_condicao_peso` é utilizada para armazenar as opções de autoavaliação sobre o peso do cidadão. Possui como referência o campo :link[Sobre seu peso, você se considera?]{id=dicionario anchor=consideracaopeso} do LEDI.

## 2. Campos da tabela

| Colunas DW | Referência |
| ---------- | ---------- |
| co\_seq\_dim\_tipo\_condicao\_peso | Código de identificação sequencial |
| nu\_identificador | Número identificador da condição de peso |
| ds\_dim\_tipo\_condicao\_peso | Descrição da condição de peso |
| co\_ordem | Código para ordenação |
