## 1. Objetivo

A tabela `tb_dim_tipo_socioeducativo` é utilizada para armazenar os tipos de medida socioeducativa aplicada ao cidadão.

## 2. Campos da tabela

| Colunas DW | Referência |
| ---------- | ---------- |
| co\_seq\_tipo\_socioeducativo | Código de identificação sequencial |
| nu\_identificador | Número identificador do tipo de medida socioeducativa |
| ds\_tipo\_socioeducativo | Descrição do tipo de medida socioeducativa |
