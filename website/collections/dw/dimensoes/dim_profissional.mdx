## 1. Objetivo

A tabela `tb_dim_profissional` é utilizada para armazenar os profissionais.

## 2. Regras

:nr A tabela é preenchida sempre que um profissional realiza um novo registro.

## 3. Campos da tabela

| Colunas DW | Referência      |
| ---------- | --------------- |
| co\_seq\_dim\_profissional | Código de identificação sequencial |
| nu\_cns | CNS do profissional |
| no\_profissional | Nome do profissional |
| st\_registro\_valido | <CampoStRegistroValido /> |
| ds\_filtro | Concatenação entre o código do IBGE, nome e UF do município, sem acentos |
